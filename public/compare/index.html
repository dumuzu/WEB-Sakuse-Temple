HTMLとCSSを比べる

同じ清水寺のページを、少しずつ変えた見本です。何が変わり、何が同じか、二つの画面で見比べましょう。

  1. 作者のCSSなし と CSSあり

    見出しと説明は同じです。文字の大きさ、色、間の違いを見ます。

  2. もとのページ と 説明だけ変更

    本堂の説明を一文だけ変えています。見た目は変えていません。

  3. もとのページ と 色だけ変更

    大きな見出しの文字色だけを変えています。

  4. もとのページ と 間だけ変更

    「本堂と舞台」の前にある空きだけを広くしています。

今日は見た目の違いを観察します。コードを直す練習は、これからの授業で行います。
