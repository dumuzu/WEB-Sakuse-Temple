# Web制作実習｜15回で学ぶこと

**清水寺のページに、小さな仕組みを足していきます。**

初めから全部を作りません。見本を使い、一つずつ変えて、結果をたしかめます。

1. **同じページに、何が加わった？**
2. **文字を、一つ変えてみる**
3. **値に、名前をつける**
4. **押したら、返事が出る**
5. **出す・隠すを切りかえる**
6. **CSSの見た目を、JSで選ぶ**
7. **写真と説明を、一緒に変える**
8. **「次へ」で、写真を送る**
9. **入力したことに、返事をする**
10. **見たい項目だけを残す**
11. **小さな機能を、組み合わせる**
12. **あとで開いても、残せる？**
13. **自分のページに、二つの機能**
14. **友だちに使ってもらう**
15. **作ったものを、残して伝える**

最後は、見本のHTMLとCSSに、小さな機能を二つ加えることを目指します。難しいときは、まず一つを自分で使えるようにします。コードを全部覚えるより、どこを変えると何が変わるかをたしかめます。
